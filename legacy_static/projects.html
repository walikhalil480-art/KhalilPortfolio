Digital Reading Platform

Understory Books

A modern digital bookstore and long-form reading environment built for literature enthusiasts and independent publishers.

The Challenge

Rendering complex editorial books on diverse web viewports typically suffers from jarring layout shifts (CLS), sluggish navigation across thousands of pages, and reader state drift when synchronizing progress between devices. Standard off-the-shelf reader components introduced heavy script payloads and lacked support for nuanced typographic styling.

The Architectural Solution

I developed a client-side chunking engine using React that parses book content progressively and caches read positions in local storage before synchronizing asynchronously with a Node.js REST API. On the persistence tier, PostgreSQL was structured with normalized tables for book editions, chapter fragments, and reader telemetry. Custom CSS font rendering and CSS Grid layouts ensured zero layout shifting during font hydration.

Retail & Commerce Engine

TillPro Point of Sale

A multi-terminal store management and checkout platform engineered for independent retail boutiques.

The Challenge

In a high-paced retail environment, slow register interfaces lead to lost sales. The client needed a system that supports instant barcode lookups, reliable multi-register cart management, and seamless offline checkout in the event of an internet disruption—without corrupting inventory numbers when connection resumes.

The Architectural Solution

I architected a local-first state layer utilizing Next.js, Redis, and IndexedDB for local registers. Cashiers can scan, adjust quantities, apply discounts, and complete transactions entirely offline. An event-driven reconciliation worker handles queued orders, syncing them to a PostgreSQL transactional database with strict stock row locking to prevent overselling.

DevOps & Cloud Topology

Cloud Infrastructure & CI/CD Pipelines

Declarative cloud environments, automated deployment workflows, and reproducible container clusters.

The Challenge

Manual deployments across staging and production frequently lead to environment drift, unverified configuration differences, and deployment downtime. Engineering teams waste valuable hours troubleshooting inconsistencies between local machines and production servers.

The Architectural Solution

I established reproducible infrastructure configurations using Terraform and Docker. Services are containerized with multi-stage builds to produce lean, minimal-attack-surface container images. Automated GitHub Actions pipelines execute automated test suites, linting, and security audits on pull requests before orchestrating rolling updates on AWS clusters with zero downtime.
